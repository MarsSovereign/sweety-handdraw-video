# v2.0.1

**这是 2.0 的第一个公开版本。** v2.0.0 只在本地打了标签、没有公开发布。v2.0.1 包含它的全部内容，见 [v2.0.0 记录](v2.0.0.md)：

- 上色像人；
- 镜头有名字和节奏；
- 22 种转场；
- 网页动效层；
- 默认比例 2:3。

在此基础上，2.0.0 交付后自查列出了 9 个问题，这一版全部修好。

## 1. 画多大不再决定画多久

- **以前**：笔画数和绘制时长按显示尺寸计算，图越大越慢。2:3 画面上的主图只好画小，或者把速度调高。
- **现在**：笔画、顺序和时间在长边不超过 720 px 的规划尺寸上计算（`drawing.plan_side` 可改），再按显示分辨率重新渲染清晰版。
- **效果**：样片放大插画后，海底图在 960×960 下从 52 笔、9.72 秒降到 35 笔、6.54 秒。它的窗口是 9.69 秒，2.0.0 会拒绝构建。

## 2. 图片问题生成后立刻发现

- **新增 `image_gate.py JOB 图 --visual <id>`**，几秒内检查：
  - 透明窟窿和光晕：这类区域会画成空白纸面，或者根本画不出来；
  - 线稿门槛；
  - 规划尺寸下的笔画数和最短秒数，与故事板给这个视觉的秒数对比。
- **不通过时给出 `prompt_fix`**，加进提示词重新生成即可；复杂度超标时写明目标笔画数。
- **实测**：样片里被退回的第一版海底图，有 26.7% 的主体是透明的。

## 3. 部位不用手描多边形

- **部位可以写成方框**：`"box": [左, 上, 右, 下]`，排除区写成 `exclude_boxes`。上色会把墨线围成的色块整块交给占它最多的部位，所以方框就够了。
- **新增 `part_grid.py JOB 图`**：输出带 0.05 网格、物体框和色块编号的图，照着写方框。

## 4. 动效有起因，少一点数码感

- **笔先动，画面才动。** 画板上的动效层出现时，笔尖沿着它描一遍：
  - 圈注时绕圈，图表和大字从下沿扫过；
  - 公式逐字跟写，3D 物件绕一圈轨道。

  笔尖悬在纸面上方，不出墨；笔正在画别的东西时跳过。`"pen": false` 关闭。
- **手写风格更统一。**
  - 大字和滚动数字默认用手写字体。
  - 进度圆环改成手绘圆，按笔画出。
  - 点阵的标记点改为交叉排线。

## 5. 故事板检查认得动效层

写了 `visual` 的动效层算作故事板里的那个视觉：图表、地图、标题、公式都算。以前只用动效层呈现的视觉会被报"缺失"。

## 6. 转场有声音

- **新增 `audio.sfx` 音效层，默认开启。** 声音对应关系：

  | 画面 | 声音 |
  |---|---|
  | 翻页、撕纸 | 纸声 |
  | 甩镜、穿越 | 风声 |
  | 墨晕、光圈 | 起伏声 |
  | 板擦、橡皮擦 | 摩擦声 |
  | 马克笔、毛刷 | 刷过的声音 |
  | 粒子 | 轻铃 |
  | 砸入 | 闷响 |
- **全部在代码里合成**，与渲染器的转场窗口逐采样对齐。人声出现时自动压低，样片实测约 -43 LUFS。
- `audio.sfx: false` 关闭，`gain_db`、`transitions`、`accents` 可分别调整。

## 7. 自动镜头不再切掉标题

- **规则**：推近时，如果画框会切过页面上已经写好的标题，就把标题纳入画框，或者移开画框；两者都不行时看全页。
- **结果**：《天涯 2027》94 个检查点中，被切的标题从 9 个降到 0 个。

## 8. 改镜头不用重画

- **素材缓存**：每个绘制元素按内容哈希缓存在 `work/asset-cache/`。只改位置、镜头、转场或动效层时，素材直接复用；改了图片、绘制参数或引擎代码会自动重画。
- **样片实测**：
  - 冷构建 26.2 秒；
  - 原样重建 5.3 秒；
  - 改开场推近和一个转场后重建 8.2 秒（第一页的画板分辨率变了，所以只重画第一页）。

## 9. 调研项全部落地

- **视差 `depth`**
  - 写在元素或画板动效层上，范围 -1（远）到 1（近）。
  - 镜头离开开页取景时，各层以 (1+depth) 倍的距离移动；远层在本页墨线下面，推近时近层向外散开。
  - 笔尖跟着它所画的那一层走。
- **希区柯克变焦 `move: dolly_zoom`**
  - 配 `subject`（某个元素的 visual id）：主体保持开始时的屏幕大小，背景冲过来或退远；下一个关键帧把主体缓回原大。
- **物理 `physics`**（matter-js 0.20.0，MIT）
  - 四种场景：倒入罐子、多米诺、球撞塌一摞方块、弹跳。
  - 每个物体保持一份手绘轮廓，跟着刚体转动，不抖线。
- **三维 `spin3d`**（Zdog 1.1.3，MIT）
  - 形状：盒子、硬币、易拉罐、圆锥、球、金字塔、宝石。
  - 平涂明暗加墨线外轮廓，先带一点过冲弹出，再转动。
- **手写公式 `formula`**（MathJax 3.2.2，Apache-2.0）
  - 每个字形先描轮廓再填实；分数线先于分母，根号先于根式里的内容。
  - 写完可以圈出、框出或划出一部分。TeX 写错时 `build` 直接报错。
- **压感线条**
  - 直线和箭头落笔渐粗、中段运笔最快处略细、收笔变尖，箭头倒钩是一下轻挑。
  - `pressure: 0` 恢复等宽的针管笔线。
- **按需加载**：三个新库只在用到对应配方时加载，许可证见 `assets/web-motion/THIRD_PARTY_NOTICES.md`。

## 验证

- **单元测试**：新增 `test_v201_features.py`，覆盖：
  - 视差与变焦的画板位置和主体尺寸、压感线宽；
  - 缓存命中与失效、规划尺寸；
  - 透明窟窿与光晕、方框部位与网格图；
  - 笔尖轨迹、动效层计入故事板；
  - 音效选项与对齐、标题不被切；
  - 三个新配方的渲染、按需加载与 TeX 报错。
- **证据**：每一项的前后对比都由 v2.0.0 标签的代码实际跑出，放在 `output/evidence/v2.0.1/`（本地，不进仓库），附索引和复现脚本。
- **演示视频**：35 秒，三页依次展示视差、变焦、物理、三维、公式和压感箭头。音频是占位音。
- **安装包**：48.1 MB，在 50 MB 上限内。

## 验收边界

- 视差层次、变焦的情绪、物理道具和三维物件的观感，以及音效的音量和音色，仍需人工看片、试听。
- 《一条消息的环球旅行》用户已经验收，成片保持 2.0.0 版不变。本版的改动在它的基准副本上验证。
- 网页动效层需要 Playwright 和 Chromium（`setup.sh --web-motion`）；没有安装时，含动效层的任务会报错并给出安装命令。

## 安装与核对

下载本 Release 的 `sweety-handdraw-video-v2.0.1.zip`，替换整个 Skill 目录。

- macOS / Linux 可在下载目录执行 `shasum -a 256 -c SHA256SUMS.txt` 核对文件。
- 安装后读取 Skill 目录中的 `VERSION`，应显示 `2.0.1`。
- 更新仓库不会自动替换已经安装的本地副本。
