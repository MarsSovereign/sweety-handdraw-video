# v1.4.1

修复版本获取不一致，以及画面元素数量足够但主体过小、内容偏空的问题。

- VERSION、首页当前版本、固定版本下载入口与包内 README 统一为 v1.4.1，新增发布前一致性检查。
- 标签发布经过 macOS / Linux 回归、离线短片和打包检查；Release 提供 ZIP、整包 SHA-256 与逐文件校验清单。
- 密集信息图和累积板书须写明焦点、至少两个辅助元素及其讲解作用；同一幅场景图可以承载多个相关元素，无需增加无关装饰。
- 构建检查实际素材像素及页面布局，排除透明或近白留白、字幕和装饰底纹；明显过小的主体会阻止生产构建，适量留白仍可说明理由。
- 老师板书在生图前定义整页分区，相关句子落在同一物理页面，已有内容保留，随口播逐项补齐；实际绘制按区域阅读顺序推进。
- 同部位、同优先级笔画改为从上到下、同高从左到右，不再由最近距离改变起笔顺序；填色区域也按空间顺序处理。整笔拓扑、原图墨迹与补角路径保留。
- 页面内容范围诊断及分镜警告保留在构建报告；设计与分镜的密度模式必须一致。绘制预算使用所选模式的实际笔忙上限且不超过70%；完成图片的静态阅读时间另行实测至少30%，任意单幅停留不足1秒均警告。
- 预留墨迹收边时间，并用描线结束处的实际笔尖位置重新分配上色预算；生产构建拒绝时间压缩、描线或上色超速。

画面范围指标用于定位小主体与闲置空间，不能代替审美和讲解效果验收；既有逐笔描线、上色、绘制时间及字幕避让检查继续执行。本次未调整配音模型或音色。另修复历史 Ubuntu CI 暴露的配乐循环/侧链尾缓冲问题，以及音频频点并列排序的可重复性问题。

## 安装与核对

下载本 Release 的 `sweety-handdraw-video-v1.4.1.zip`，替换完整 Skill 目录。macOS / Linux 可在下载目录执行 `shasum -a 256 -c SHA256SUMS.txt`；安装后读取 Skill 目录中的 `VERSION`，应显示 `1.4.1`。更新仓库不会自动替换已经安装的本地副本。
