# v2.0.0

> 这一版只在本地打了标签，没有公开发布；它的全部内容随 [v2.0.1](v2.0.1.md) 一起发布，请安装 v2.0.1。

1.5 让画面干净、复杂图有条理。2.0 主要做四件事：

- **上色**：不再一块一块地出现，改成像人一样先描边、再排笔。
- **镜头**：有了名字和节奏，自动导演每页都不一样。
- **转场**：从 16 种扩到 22 种，翻页和擦除成为章节的招牌。
- **网页动效层**：能做大字、手绘图表、地图路线和形状接力。

**默认比例从 9:16 改为 2:3（1280×1920）。** 新做的样片《一条消息的环球旅行》（2:3，逼真男声）用到了以上全部能力。

## 上色 v4

- **不再按部件矩形切块。** 模型给部件画的多边形通常是方框，会把一块连续的颜色切开；上色又是按部件进行的，所以原来会一个矩形一个矩形地出现。这就是"一块儿一块的"的主要原因。现在的做法：
  - 墨线围住的区域里，每一块同色区域整块交给占它最多的部件；
  - 细缝、阴影线随最近的整块走；
  - 墨线完全围住的小块（扣子、道具）保留原归属；
  - 部件框只用来给墨线分组。

  在 6 张测试图上，被部件边界切开的颜色面积从 28–87% 降到 0–0.9%。
- **先描边，再排笔。** 人上色的顺序被拆成四步：
  - 先沿区域内侧描一圈边；
  - 长条形状横跨着画，圆形用右手自然的斜度排笔；
  - 太宽的形状分成几条带（lane）；
  - 相邻的笔连成一笔不抬笔，漏掉的角落最后补涂。
- **湿笔触。** 刚涂上的颜色带毡头纹理，是半透明的；下一笔覆盖上来，或稍后才变实，在一两帧里推进，不再"盖章"。
  - 衡量指标是首次出现就已是最终颜色的像素比例：从 66–90% 降到 1–12%。
  - 每个像素的过渡都保证在本段结束前完成，终帧仍与原图逐像素一致。
- **窗口紧时退回。** 最宽的马克笔沿用原来的长行快涂，不描边，所以绘制最短时长不增加：5 张图更短，1 张略长（8.68→8.89 秒）。
- **大画板推近时也清晰。** 推近用的放大版本里，毡头纹理改为插值放大，不再出现马赛克。

## 镜头 v3

- **命名运镜。** `move`：cut、push_in、pull_out、pan、drift、hop、whip、snap、slam，各自带默认时长和缓动，时长参照花叔《镜头语言》的实测值。
- **缩放在对数空间插值。** 放大一倍和再放大一倍用时相同。
- **新增两个参数。**
  - `hop`：长距离移动途中先拉远约 30%，看清去向再推进。
  - `impact`：到位时有衰减的震动，0.18 秒的"砸入"就靠它。
- **自动镜头。** 各页轮流使用三种拿图方式：静止、慢推、跟随笔尖。远距离用 hop，翻页前拉远看全页。
- **密度门禁**（build 报警告）：
  - 甩、砸、急推不超过全部运镜的 1/3；
  - 不连续三次推近；
  - 推近每分钟不超过 8 次；
  - 同一种设计转场不连用三次。

## 转场（22 种，另有若干变体）

- **纸张**
  - `page_turn` 支持四个方向：向前翻、往回翻、便签本上翻、下翻。
  - 新增：撕纸 `paper_tear`（撕口带白色纸纤维，两半各自落下）、立方体 `cube`、拼砖 `tiles`、碎片 `shards`。
- **擦除**：`erase` 增加 `style: rubber`，橡皮擦来回擦，碎屑堆在每行尽头，最后掸掉。
- **墨与笔**：新增毛刷刷出 `brush_reveal`（带干笔飞白），`iris` 增加墨渍边 `style: blot`。
- **点缀**：新增闪白 `flash`。
- **自动转场。** 章节轮流使用招牌转场：翻页、便签上翻、板擦、撕纸。其余页面用轻转场，每三页放一个设计转场，相邻两页不重复。

## 网页动效层

- **大字**：`kinetic_title` 新增三种样式：
  - `slam`：逐词砸入并震屏；
  - `scramble`：乱码收敛成字；
  - `word_by_word`：逐词出现，关键词先大后缩、把旁边的词挤开。
- **新配方**
  - `morph`：形状接力。点变卡片、卡片变心形，先拉伸后变形，颜色一起过渡。
  - `rough_chart`：手绘图表。柱、线、饼、点阵、按笔顺写"正"字计数、时间线，先画坐标轴，再出数据，最后强调一项。
  - `map_route`：路线地图。可以是转动的地球或平面地图，航线随标记画出，站点依次弹出。只画海岸线，不画国界。
- **防截断**：大字自动缩小到放得进框；动效层最终帧碰到框边时 build 报错（`"bleed": true` 表示有意出血）。
- **新依赖**（均为 ISC）：d3-geo、d3-array、topojson-client、world-atlas 陆地轮廓。许可证见 `assets/web-motion/THIRD_PARTY_NOTICES.md`。
- **安装**：`setup.sh --web-motion` 安装 Playwright 和 Chromium，`setup.sh --check` 会报告它是否可用。

## 默认比例 2:3

- 未指定比例时用 2:3（1280×1920），原来是 9:16（1080×1920）。9:16 仍可选，需要全屏短视频时选它。
- 字幕一行容量、版式安全区（`layout_plan.py`）和原生选项菜单的默认项都随之改变。

## 给模型的"卡组"

新增 `references/motion-catalog.md`，列出全部运镜、转场、动作和动效配方。每张卡写明：

- 做什么、默认参数；
- 适合什么、不适合什么；
- 拒绝清单：故障风、光扫、无因粒子、半秒内连闪；

SKILL.md 与运行格式文档都改为指向这份目录，镜头和转场由模型逐镜设计，自动导演只补缺。

## 样片与验证

- **《一条消息的环球旅行》**：60.6 秒，2:3，逼真男声；6 页、6 幅插画、14 个动效层，转场全部按情节设计：
  - 穿越推：钻进手机；
  - 墨渍光圈：进入光纤；
  - 深海蓝墨晕：潜入海底；
  - 便签上翻：打开地图；
  - 甩镜：跨过太平洋。

  事实依据记在 `design.json`。build、verify、finalize 全部通过；连续观看和真人试听由用户完成。
- **样片暴露并修好的问题**

  - 旁白里单独的“叮”被语音识别漏掉，这条字幕时长为零，build 拒绝：开头漏识的音节改为归入第一条字幕，按实际发声起点计时。
  - 多进程渲染拼接时帧时长被取整，帧率报成 29.9997，verify 拒绝：每帧一个时间刻度，并按整帧截断。

## 验收边界

- 观感指标只用来发现明显问题，不是审美分数。
- 湿笔触、运镜节奏和各种转场的观感，仍需人工看片。
- 网页动效层需要 Playwright 和 Chromium；没有安装时，含动效层的任务会报错并给出安装命令，不会静默跳过。

## 安装与核对

下载本 Release 的 `sweety-handdraw-video-v2.0.0.zip`，替换整个 Skill 目录。

- macOS / Linux 可在下载目录执行 `shasum -a 256 -c SHA256SUMS.txt` 核对文件。
- 安装后读取 Skill 目录中的 `VERSION`，应显示 `2.0.0`。
- 更新仓库不会自动替换已经安装的本地副本。
