# v2.0.2

用户看完 2.0.1 的正式样片《用一天，重启你的人生》后提了两个问题：

- 有几处字是在画面外写的：笔在动，观众却看不到它在写什么；
- 有几句台词的结尾有杂音，听起来像断了一下，或者少念了一个字。

这一版把两个问题都从生成逻辑上修掉，两部样片也用新逻辑重新出片。修复过程中顺带发现了第三个问题（两条大标题会被连读成一句），一起修了。

## 1. 笔不在画面外写字

**原因**：镜头按句子设计，笔画的时间按画面复杂度安排，两者各算各的。一句话开始时镜头推到左边，而右边那幅图可能还没画完；标签写在推近画面的边缘外；提问气泡在镜头还没转过去时就弹出来了。

**做法**：`build` 新增取景检查（`scripts/framing.py`），在时间线排好之后运行。

- **检查范围**：每个正在写或画的元素，在它的绘制窗口内每 0.25 秒检查一次。
  - 文字、线条、标记：整块都要在画面内，离画面边和字幕带至少 24 px。画面边已经到画布边时不要求留边，因为镜头已经无路可退。
  - 插画：笔尖要在画面内。推近只拍一幅大图的一部分是正常构图，但不能离开正在画的地方。
  - 画板上的动效层（气泡、圈注、落下的照片、物理道具）：在它出场的过程中，整个框都要在画面内。
- **不在画面内时，试下面几种修法**，挑整页效果最好的那个：
  - 镜头等笔：画到一半就开始的镜头，推迟到这一笔画完；
  - 插一个取景镜头，三种取法：
    - 平移一点；
    - 把元素居中；
    - 拉远到同时装下原来的画面和新元素。

    随后几秒要画的元素如果也装得下，就一起框进来，镜头不会一个标签追一下。
- **怎么算好**：先比笔在画面外写画的量，再比动效在画面外的量。为了接住一个气泡，把正在画的图甩出画面，这种修法不会被选中。哪种修法都不能让整页变好时，保留原镜头，在 `build` 警告里写明页码、元素和偏出的像素。
- **不破坏镜头设计**：
  - 开页取景不推迟；
  - 后面的镜头仍按原来对应的台词时间走，只在前一个镜头还没走完时顺延；
  - 页尾放不下的镜头去掉，最后一个（交给翻页的那个）保留。
  - 插入的镜头带 `"auto": "framing"`，记录在 `timeline.framing`。

**效果**：同一部片子分别关掉、打开取景检查构建，按同一标准统计：

| 样片 | 2.0.1 的镜头 | 2.0.2 |
|---|---|---|
| 《用一天，重启你的人生》（188 秒） | 13 处：9 处笔在画面外写画，4 处动效在画面外出场 | 0 |
| 《错话，该不该翻译？》（93 秒） | 2 处：都是插画还没画完，镜头就先走了 | 0 |

## 2. 句尾干净

**原因**：每段旁白生成后，按"语音能量"裁掉首尾静音，再留 100 ms。这个判断会被两种声音骗过：

- 句尾的气声：裁剪点正好落在气声中间，硬切，听起来像断了一下；
- 模型在句子说完后多出来的一小段声音：被当成语音保留，听起来像多了半个字。

**做法**：

- 从 ASR 给出的最后一个字往后，找第一段低于 -40 dB、持续 30 ms 的静音，以它作为句子的结尾。
- 结尾之后高于 -30 dB 的声音，一并删掉。
- 保留 0.12 秒余音，再用至少 50 ms 的余弦淡出；开头加 10 ms 淡入。
- 末尾仍高于 -25 dB、又找不到静音时，说明句子本身被截断了：这一段判为失败，换种子重新生成。
- 新增 `narration_master.py rebuild JOB`：已有分段按新规则重新拼母带，不加载模型。拼接规则更新后，旧片不用重新合成。

**效果**：

| | 2.0.1 | 2.0.2 |
|---|---|---|
| 《用一天》34 句中，结尾高于 -60 dBFS 的句子 | 9 句（气声上硬切，最高 -41 dBFS） | 0 句（全部 ≤ -74.5 dBFS） |
| 模型在句子说完后多出的声音 | 2 段（0.27 秒、0.09 秒），其中一句结尾在 -10.9 dBFS | 删除 |
| 《错话》19 句 | — | 19 句都判为干净 |

## 3. 两条大标题不再连读

屏幕顶部的大标题换下一条时，上一条正在淡出，下一条已经出现。一些逐字出现的标题因此会被连读成一句，比如"批评的"接上"门是开着的"。现在同一位置的两条标题会轮流出场：后一条出现前，前一条先淡出；如果来不及，就在自己入场动画一结束时离开。

| 样片 | 同一位置的标题交接 | 2.0.1 重叠 | 2.0.2 重叠 |
|---|---|---|---|
| 《错话》 | 10 次 | 8 次 | 0 |
| 《用一天》 | 6 次 | 3 次 | 0 |

## 4. 另外两处小修复

- `image_gate` 只把半透明的填充（alpha 8–200）算作"透明窟窿"。插画里本来就镂空的地方（门洞、手臂之间的空隙）不再被误报。
- `spin3d` 在高分屏上不再被放大两次：画布按 CSS 像素设定尺寸。

## 验收边界

- 取景检查只管"正在画的东西在不在画面里"，不判断构图好不好看。推近时屏幕大标题压到画面，仍要人看片后在分镜里处理（让标题先退场，或者改推近的中心）。
- 句尾规则作用于按段生成的旁白。有 ASR 字时间时，从最后一个字找起；没有时，从按能量判断的语音结束前 0.4 秒找起，判断会粗一些。用户自带的整篇录音不经过这一步。
- 两部样片的连续观感和听感，需要人工看片、试听。

## 安装与核对

下载本 Release 的 `sweety-handdraw-video-v2.0.2.zip`，替换整个 Skill 目录。

- macOS / Linux 可在下载目录执行 `shasum -a 256 -c SHA256SUMS.txt` 核对文件。
- 安装后读取 Skill 目录中的 `VERSION`，应显示 `2.0.2`。
- 更新仓库不会自动替换已经安装的本地副本。
