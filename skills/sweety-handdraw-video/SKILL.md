# 主题手绘视频

交付可播放成片、封面、字幕、口播稿和检查记录。默认简体中文、1920×1080、30fps；用户的语言、尺寸、画风、声音和复用要求优先。片长随内容和实际配音变化，不固定页数、布局或每页秒数。

先读[依赖路由](references/dependencies.md)，再按需读取内置指南。主体内容由模型设计；脚本只执行已确定的素材与时间线，并用客观指标拦截错误。只有主题、故事、正文、附件全部缺失时才暂停索要；其余偏好都有默认值，不构成阻碍。宿主无法生成图片时停止并告诉用户，不能静默降级成纯文字视频。

## 流程

1. **讲清因果。** 确定受众、要解决的问题、机制、必要反例与行动，写入 `design.json`。改编文章先读全文，保留限定、署名与来源；时效或有争议的事实核实一手资料。用户给了稿子就改错不改意：只修事实错误和不顺口处，保留作者观点与有意的简化，篇幅增长不超过约20%，改动记入 `script_changes`。详见[创作与分镜](references/story-design.md)。
2. **开始时给可选项。** 按[可选制作设置](references/production-options.md)准备默认方案，依次展示画风、手臂/仅笔、声音、笔杆广告、浮动水印和字幕；已明确的选项直接沿用，每项最多等60秒，超时用默认值继续。画风展示真实预览并标明绘制方式：有清晰墨线轮廓、平涂上色的画风**逐笔绘制**；水彩、水粉、纸雕、像素、写意等无轮廓画风用**揭示**（手带软笔刷按部位显出原图）。由模型选画风时（默认方案、自动匹配、用户委托），从逐笔绘制、上色的 4、5、17、19、20 中按内容选；纯黑白的 1 号须写 `monochrome_reason`。揭示放弃了逐笔绘制，只能由用户亲自选：在窗口点标“揭示”的卡，或模型先说明“这个画风只能刷出、不能画出”、用户同意后把答复写进 `reveal_accepted`。模型不能因超时、委托、自定义描述或某张图画不出来而改用揭示：画不完就简化画面，画不像就调整笔画。广告、水印默认不加，不杜撰品牌或署名。
3. **旁白先行，按段落生成。** 先写完整口播稿，再按语义段落（每段不超过约100字，只在句末切）逐段生成；每段通过噪声门禁（嗡声、底噪、削波）才保留，不通过换种子重试；拼成母带时用实测停顿，并自动生成 `alignment.json`，不手写时间戳。本地 VoxCPM2 或 VoiceStudio 是主力；火山豆包、Gemini TTS 只在用户自己配置了密钥时作为选项。用户自带录音用 `align.py` 对齐。默认不加背景音乐。详见[连续旁白](references/continuous-narration.md)、[声音与依赖](references/local-runtime.md)、[VoxCPM2 要点](references/voxcpm2.md)。
4. **分镜先算预算，再生图。** 导演按句设计镜头、只留最有表现力的画法，拆出每个镜头的视觉元素，写 `storyboard.json`；运行 `storyboard_lint.py JOB --budget`，由脚本按真实旁白算出需要的视觉数、每个视觉可用的绘制秒数和复杂度档位，数量不足就在最稀疏的镜头补。图按可用时间设计，不是画完再压缩时间。图约以3倍人速画完就停住给观众看，笔在画的时间不超过旁白的70%；列举、分类类内容在一块板上逐句累积，不每句换页重画。长片按章节推进，用 `plan_status.py` 找下一个镜头。
5. **出图：可画、可认、可分部位。** 每次生图或改图前都执行美术指导（见下节）。先写 `drawing-plan.json`（主体、部位、顺序、`identity_cues`）并运行出图前检查。逐笔绘制的图要连续干净的墨线、部位交界闭合、平涂不加纹理线，复杂度符合档位，见[可绘制约定](references/style-and-drawing.md)。先做一张代表图，核对主体、构图和部位可分性，再扩展同片素材；新主题重新设计，修订本片或用户明确复用时保留已通过的图。封面 AI 只出主视觉，准确标题用可编辑文字图层合成。出图后依次：看图填写叙事核对（咬伤、断裂、接触、得失等必须真实可见）；`drawing_contract.py JOB --thumbnails` 缩略图1秒内叫得出名字；`lineart_gate.py` 线稿门槛；`region_marks.py` 看编号叠图把区域分给部位，交界不闭合时改用部位多边形。所有生成图执行 `clean_image.py` 隐私清理。
6. **编排与代表段。** 按[运行格式](references/runtime-contract.md)写 `job.json`：动作带 `visual`，一个镜头通常是跨句的 `visual_group`，`from_beat` 让元素在对应句开始时起笔；页面可设镜头关键帧与转场。中文按标准笔顺书写（GB2312 内汉字），其余字符按字形描线。字幕按[字幕设计](references/subtitle-design.md)，收尾按[声音与收尾](references/audio-and-ending.md)。固定封面1秒（前0.5秒静止、后0.5秒渐隐）后开始正文。先渲染覆盖文字、插画、上色、字幕与转场的代表段，其中至少一幅插画从头画到尾，按播放尺寸看，再渲染整片。判断标准是“像不像正在画”：先看画面怎样形成（笔尖带出线条、先轮廓后上色、没有整块显现、方向顺手），再看成图是否好看；出现碎线、飞白、灰斑就先改图，不要先批量出图。
7. **核对后交付。** `build` 先在旁白上检查字幕同步和字幕避让（插画像素不得压进字幕区），不等渲染后才发现；`verify` 对成片做工程检查、声音门禁与字幕同步复核；再按[质量检查](references/quality-gates.md)看画面与内容。连续播放和听音在 `review.json` 单独记录（`continuous_playback`、`listening`），没做就写 `not_done` 和原因，回执会把它列为未完成，不并进“通过”；不把解码、ASR 或文件存在说成观感保证。`finalize` 只接受与当前视频匹配的检查记录。用户拒绝成片时运行 `handdraw_video.py reject JOB --reason "用户原话"`：回执改为“用户已拒绝，需要返工”，这一版视频不能再 finalize。交付时告知：默认未加背景音乐；成片已写入 AI 生成隐式标识，发布时仍须在平台声明“AI 生成”。

构建和渲染会拒绝：未锁定旁白与时间戳、缺少 storyboard 或其检查失败、绘制窗口短于图像的 `minimum_seconds`、线稿门槛失败、部位不匹配或整人单块、声音门禁失败、检查记录过期。模型修正对应层后继续；偏好未选不触发这些门槛。脚本只核对结构、哈希、像素与声学指标，不能替代模型看图判断和真人试听。

## 所有生图必须先经过美术指导

每次调用生图或图片编辑工具前，完整读取并应用 `dependencies/sweety-image-art-direction/GUIDE.md`；这是用户对本项目的明确授权，不受它独立使用时“仅手动触发”的限制。封面、正文、角色、道具、新手部、候选、变体、局部修改和返工全部适用。库内画风保留完整配方；独立推理和自定义画风只用各自的风格说明。

先把本图简报（含分镜给出的绘制秒数和复杂度档位）与完整提示词存进任务目录，在美术记录登记 `brief_file`、`prompt_file`，运行 `python scripts/art_direction.py bind-evidence <记录路径>` 绑定哈希，再调用图像工具；禁止先出图再补记录。生成后实际看图，记录清理后哈希和视觉结论。缺记录、哈希失配、未通过看图或图片被替换，构建、渲染和交付都会停止。复用已验收且字节不变的素材可沿用原记录。

## 字幕唯一性是交付硬门槛

同一句旁白同一时刻只显示一份字幕：画面烘焙、字幕事件、MP4 字幕轨、网页 `<track>` 和播放器自动加载的字幕文件不能叠加。只从无字幕素材和独立字幕层重新合成；编辑用字幕只放 `outputs/editing/`。交付检查 MP4 无额外字幕轨、同目录无 SRT/ASS/VTT，并实际看解码画面的长句、换句和片尾，出现双字幕直接判 FAIL。

## 声音

目录有六款：逼真男声、逼真女声（原片参考，只在本机个人声音库，需先导入）和四款随包的合成声音——磁性解说男声（默认）、儒雅青年、温柔知性女声、悬疑故事解说。本机个人库里已验收的主力音色优先，用户本次的明确选择最优先。用户可添加任意数量的自定义声音：本人录音声明 `consent: self`，他人声音须获授权并声明 `consent: authorized`；参考在导入和每次使用时都要过门禁。不克隆公众人物、主播或平台音色，不用合成试听冒充原片音色。来源与授权见[声音来源](references/voice-sources.md)。不自动购买服务、下载模型、改全局引擎或交付无声片。

## 手部和广告

六款手臂：`navy` 深蓝袖马克笔、`diamond-woman` 碎钻长甲、`child-pencil` 儿童彩铅、`waner-brush` 上官婉儿灵感毛笔、`teacher-pen` 白衬衫中性笔、`cardigan-fountain` 针织袖钢笔；另有 `pen-only`：`navy` 同一支笔去掉手臂（角度、笔尖、尺度不变）。模型按内容选默认，锚点在 `assets/hands/catalog.json`。手臂按笔尖到手腕校准，裁切边留在画外。

`hand.pen_text` 只在笔杆加广告，最多16个字符，默认空，保持用户原文。`watermark.text` 生成低不透明度缓慢浮动的文字水印，默认空，避开字幕。参数见[可选制作设置](references/production-options.md)。

## 运行与边界

首次使用运行 `scripts/setup.sh` 安装依赖（macOS、Linux；Codex 与 Claude Code 均可）。`scripts/handdraw_video.py` 提供 `doctor / build / render / verify / finalize / reject`；`doctor` 列出可用的配音后端、字体覆盖和渲染条件，缺什么报告什么。任务数据放独立目录，不写入安装目录。手部、画风预览和合成声音随包分发；原片录音与个人声音库只存本机。

质量优先：工程门槛保证顺序与完整性，模型仍要审查语义分区、画风和叙事。真实手写自然度、情感和学习效果须分别评价。不承诺任意主题一次稳定生成，不发布视频、不开通服务、不改全局模型配置。
