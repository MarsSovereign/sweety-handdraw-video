# sweety-handdraw-video

安装一个 Skill，按主题或文章制作完整手绘讲解视频。当前版本：v1.4.1。

- 使用入口：[SKILL.md](SKILL.md)
- 项目说明、安装与样片：[GitHub README](https://github.com/threerocks/sweety-handdraw-video)
- 开始时的可选设置：[配置类型、比例、风格、声音与字幕](references/production-options.md)
- 编写任务：[运行格式](references/runtime-contract.md)
- 字幕与收尾：[模型设计规则](references/subtitle-design.md)
- 内置依赖和冲突处理：[依赖路由](references/dependencies.md)

旁白以本地为主：已安装并明确配置的 VoxCPM2，或兼容的本机 VoiceStudio 服务；火山豆包、Gemini TTS 只在用户配置了自己的密钥并选择时使用；已核对的导出音频可以离线复用。音色目录与试听见[本地声音运行](references/local-runtime.md)。生成新图片还需宿主的图像工具（Claude Code 需接入生图工具 / MCP 或使用用户提供的插画）；Python、fontTools 与 FFmpeg 负责本地合成，图片隐私清理为纯 Python。支持 macOS 与 Linux，`scripts/setup.sh` 一次装好运行环境。内置的参考指南不需要另行安装为 Skills。

### v1.4.1：发布入口与画面丰富度

- 版本说明、固定下载链接、安装包与标签一致，提供整包与逐文件 SHA-256 校验。更新后读取本目录 `VERSION`，应为 `1.4.1`。
- 密集画面声明焦点和至少两个有讲解作用的辅助元素，可以放在同一幅场景图内；主体过小会阻止生产构建，留白需有理由。
- 构建报告记录实际页面内容范围、分镜警告；这些检查不替代看图验收。

### v1.4：原生选项、竖屏默认、导演密度

- **原生选项，不弹网页。** 先选配置类型：模型推理（默认）或主动选择。主动路径只问比例 → 风格（文字列表，无预览）→ 声音 → 字幕；兼容 Claude Code / Codex / TTY。
- **默认 9:16（1080×1920）**，另有 3:4、2:3、16:9、4:3、3:2 与自定义。
- **风格默认模型推理**，目录为软参考、不约束模型；揭示仍须用户明确接受。
- **presentation.mode 导演密度**：绘本稀疏 / 科普密集 / 板书累积等，由模型推断，lint 强制执行。
- **拟人绘制**：部位切换短暂停顿；线+色连续之字；pause 段计入抬笔时间。

### v1.3：像人一样画、按段配音

- **分镜先算预算。** `storyboard.json` 写镜头与视觉元素，`storyboard_lint.py --budget` 按真实旁白算出需要几个视觉、每个能画几秒、复杂度上限（约每秒3.5笔），图按预算设计，不是画完再压缩时间。
- **两种绘制方式。** 有墨线轮廓、平涂上色的画风（库内 1、4、5、17、19、20）逐笔绘制：整笔描线、先主后次、右手顺序、抬笔移动、马克笔之字形上色；其他画风用揭示：手带宽软笔刷按部位斜向扫出原图。画风选择器标明每种画风的方式，`style/resolved.json` 的 `drawing_mode` 必须与任务一致。
- **汉字按标准笔顺书写**（GB2312 内的字，数据来自 hanzi-writer-data），其余字符按字形描线。
- **旁白按语义段落生成。** 每段不超过约100字、只在句末切，逐段过噪声门禁（嗡声、底噪、削波）和语速 / ASR 检查，不通过换种子重试；拼接停顿实测，自动写 `alignment.json`。改稿时只重生成文字变了的段落，其余已通过的段落直接复用（分段位置不变时）。
- **声音目录。** 逼真男声、逼真女声（本机原片参考）＋四款随包合成声音（磁性解说男声为默认），可添加声明授权的自定义声音。
- **交付。** `verify` 增加声音门禁和字幕同步检查；成片写入 AIGC 隐式标识元数据，发布时仍须在平台声明“AI 生成”。

### v1.2：整篇声音优先

整篇生成/录制并核对旁白后锁定母带，画面和字幕读取母带时间戳。生产构建拒绝逐页音频拼接、固定换图静音、裁换气和变速；验证母带与时间戳哈希，并逐样本检查主体旁白保持完整。详见 `references/continuous-narration.md`。

### v1.2：指定原片音色与纯旁白修复

原片音色不再以合成试听继续克隆。导入参考与逐字稿绑定哈希，VoxCPM2 默认同时使用原参考和准确逐字稿；本机已验收的主力音色保存在个人声音目录中，不进入公共包。参考清理、同文对照、正文短样和完整旁白分别验收；没有附加配乐不代表旁白内部没有杂音。

字幕默认白字黑边，禁止重复字幕；编辑用字幕独立放在 `outputs/editing/`。v1.3 起手部、画风预览与试听随包提供，缺失或损坏时按镜像修复，见[托管与缓存](references/hosted-assets.md)。当前女声暂用，保留原片参考，后续继续调整；不是最终听感验收。

### v1.2.1：美术指导检查加强

每次出图前必须读取内置美术指导，并准备非空简报与实际提示词、绑定内容哈希；生成后填写真实看图结论。缺记录、空文件、提示词或图片改变均停止生产。详见 SKILL.md 的强制流程。

### v1.2.3：音色目录收敛

选择器、源码与引导统一为当时的六项（v1.3 已替换为上文目录）。个人或任务内的旧条目不会加回目录，旧名称也不会覆盖当前名称。当前逼真女声仍为暂用状态。
